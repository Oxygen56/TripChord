# 平台接入与当前支持情况

本文面向想了解 TripChord 数据从哪里来、当前能查到什么的用户和开发者。表里的“已接入”表示代码已经具备查询和解析能力，不等于每次都能取得可比较的当前报价；是否成功，以每次行程结果中显示的平台、查询时间和报价内容为准。

TripChord 只读取查询结果，不下单、付款、领取优惠、修改账号或绕过验证码。它比较的是**本次实际查到、日期、人数、产品和费用口径能够对上的结果**，不宣称全网最低价。

## 当前来源

| 来源 | 当前用途 | 当前情况 |
| --- | --- | --- |
| 携程 | 国际机票、海外住宿 | 已接入本机 Chrome 只读查询，真实运行中取得过与日期和人数绑定的机票、住宿报价。结果只代表查询当时，不锁定库存。 |
| 去哪儿 | 国际机票、海外住宿 | 已接入本机 Chrome 只读查询，真实运行中到达过准确的机票结果页；近期住宿运行尚未稳定取得第二个可与携程公平比较的准确报价。 |
| 同程 | 国际机票 | 已取得过真实机票观察；近期查询也遇到过账号或登录风险页。海外住宿在一次只读查询返回需要登录且没有报价后已停用，不作为等待用户处理的事项。 |
| 飞猪 | 国际机票候选来源 | 因反复出现验证页，无法稳定完成无人值守的只读查询，当前不进入正式比较。 |
| iCom / RTL 公开页面 | 马尔代夫机场与岛屿接驳 | 用于核对路线、班次和参考价格。公开接口没有提供可锁定库存，税费不完整时只能作为估算。 |
| Amadeus | 机票 API | 查询与价格确认适配器已经实现；当前仓库没有配置可用于真实运行的凭据。 |
| Booking.com Demand API | 住宿 API | 搜索与可用性适配器已经实现；当前仓库没有配置合作方凭据。 |
| 高德地图 | 地理编码、地点、路线与天气 | 适配器已经实现；当前仓库没有配置 Web Service Key。 |
| Open-Meteo | 地理编码与天气 | 已完成公开接口的真实只读检查；只提供天气信息，不提供机票或酒店价格。 |
| 用户提供的报价 | 补充比较 | 可以导入用户明确提供的页面快照；必须标为用户快照，不能伪装成 TripChord 刚刚查询的结果。 |
| 保存数据回放 | 开发与验收 | 用于重复运行同一条规划链，不访问平台，也不代表当前价格或库存。 |

新增平台不会自动获得“正式支持”身份。只有它能稳定返回与本次路线、日期、人数、房间和税费口径绑定的结果，才会进入最终价格比较。

## 一次查询可能得到什么结果

平台没有返回价格，不一定代表没有票或没有房。TripChord 将下面几种情况分开记录：

| 显示结果 | 实际含义 |
| --- | --- |
| 找到准确报价 | 在查询当时看到了与本次地点、日期、人数和房间数对应、可以统一计算的价格；仍不是库存锁定。 |
| 已确认没有结果 | 同一查询经过重复观察后，页面明确返回空结果；只对当时这次查询成立。 |
| 有限范围内没有找到准确报价 | 已完成预先限定的页面查看，但没有找到信息足够完整的价格；不能推断整个平台都无库存。 |
| 平台仍在查询 | 页面在限定等待时间结束时仍显示加载或搜索中；不能当成无结果。 |
| 登录或验证码阻断 | 本次无法继续读取，TripChord 跳过这个来源，不会尝试绕过。 |

只有“找到准确报价”才能进入跨平台价格比较。平台页面能打开、适配器已经实现或一次测试通过，都不能代替准确报价。

## 本机浏览器怎样参与

使用携程、去哪儿或同程等网页来源时，Chrome Companion 在用户自己的已登录浏览器中读取指定平台页面上可见的信息。用户决定允许哪些域名；平台密码、Cookie 和整个 Chrome 用户目录不会发送给模型。

TripChord 只允许搜索、筛选和读取结果所必需的操作。任何下单、付款、接受条款、修改或取消预订都不在产品能力范围内。页面要求验证码或重新登录时，本次查询直接跳过该来源。

## 交通与接驳边界

TripChord 不使用未公开的 12306 接口。铁路方案只会采用公开时刻或用户确认的页面快照，最终余票与购买仍由用户在官方渠道确认。

智行的 PC 网页机票与酒店入口在 2026 年 8 月的检查中主要引导到 App 或小程序，没有形成能够稳定读取并核对完整报价的网页结果，因此目前只作为候选来源，不进入正式比较。

马尔代夫 RTL / iCom 的路线详情来自当前公开页面，但接口没有稳定公开文档，随时可能变化。具体观察边界见 [机场与 Hulhumalé 接驳核对记录](rtl-airport-hulhumale-audit.md)。
